Quaestor. Phase one point five.

An agent presents a signed authorization — capped, scoped, time-limited.

Core verifies it. Derives a fresh key. Signs the payment in process. The key never touches disk.

The bridge wraps the signature and forwards. It cannot read the key. It cannot replay the signature. It can only relay.

Twelve seconds later — settlement on Base Sepolia. Public. Verifiable. Final.

Every other agent payments stack asks you to give up the keys.

Quaestor doesn't.
